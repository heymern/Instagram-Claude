# Start here

Everything for Nuveau's Instagram lives in this GitHub repo
(heymern/Instagram-Claude). You don't need a laptop: it all works from your iPad.

## How to start a session

1. Open **claude.ai/code** in Safari (or the Claude app).
2. Pick the repo **heymern/Instagram-Claude**.
3. Pick the environment **Instagram-Claude** (not "Default").
4. Type a command, for example `/ig-reel` followed by your idea.

## The 13 commands

| Type this | To get |
|---|---|
| `/ig-reel` | Hooks, script, on-screen text and timing for a Reel |
| `/ig-caption` | A caption with hashtags, checked before posting |
| `/ig-carousel` | Slide-by-slide carousel copy and image files |
| `/ig-story` | The day's Stories, frame by frame |
| `/ig-plan` | This week's posting plan |
| `/ig-repurpose` | A week of posts from one long video or blog |
| `/ig-viral` | What's working in your niche right now (a swipe file) |
| `/ig-audit` | What's working in your own past posts |
| `/ig-profile` | Your profile scored out of 100, with fixes |
| `/ig-comment` | Comments to leave on other accounts' posts |
| `/ig-reply` | Replies to comments on your posts |
| `/ig-dm` | DMs and follow-ups |
| `/ig-human` | Makes any draft sound less like AI |

Tip: say who is speaking ("/ig-reel for Randy about HydraFacials") and the
script will be written in that person's voice.

## Where things are

| What | Where |
|---|---|
| Your brand voice | `instagram/voice.md` |
| Weekly plan, swipe file, log | `instagram/` (the skills create these) |
| The skills themselves | `.claude/skills/` |
| Instructions Claude reads every session | `CLAUDE.md` |

To change your voice (new staff member, new words), just ask Claude:
"Update voice.md: Lauren has started, she's our new injector."
